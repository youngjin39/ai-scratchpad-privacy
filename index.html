AI Scratchpad 개인정보처리방침

시행일: 2026년 10월 13일

이 방침은 Android 앱 AI Scratchpad(패키지 dev.aiscratchpad.ai_scratchpad, 이하 "앱")가 사용자 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 개인정보

앱은 개인정보를 수집하지 않습니다. 앱에는 계정, 로그인, 분석 도구, 광고, 오류 보고 도구, 클라우드 동기화가 없으며, 앱은 인터넷에 연결하지 않습니다. 개발자는 사용자가 작성하거나 연 글과 파일을 받거나 볼 수 없습니다.

2. 기기 안에서 처리하는 정보

  • 편집 중인 글: 앱이 종료되어도 이어서 쓸 수 있도록 기기 안의 앱 전용 공간에 임시로 보관합니다.
  • 저장 복구 사본: 저장이 끝까지 확인되지 않은 경우 저장 전 원본과 저장하려던 내용을 앱 전용 공간에 보관합니다. 사용자가 확인한 뒤 삭제할 수 있습니다.
  • 최근 파일 목록: 사용자가 열거나 저장한 파일 최대 10개에 다시 접근하기 위한 정보를 앱 전용 공간에 보관합니다.
  • 열고 저장하는 파일: 사용자가 시스템 파일 선택기에서 직접 고른 파일과 위치에만 접근합니다. 앱은 기기 저장소 전체에 접근하는 권한을 요청하지 않습니다.

이 정보는 기기를 벗어나지 않습니다. 앱은 Google 클라우드 백업을 사용하지 않습니다. 다만 사용자가 Android의 기기 간 데이터 이전 기능을 사용하면 편집 중인 글이 새 기기로 함께 옮겨질 수 있습니다.

3. 다른 앱과 주고받는 정보

사용자가 다른 앱의 공유 메뉴에서 AI Scratchpad를 고르면 그 앱이 보낸 텍스트나 파일을 받아 엽니다. 사용자가 앱에서 공유나 복사를 고르면 해당 내용이 사용자가 선택한 앱이나 클립보드로 전달됩니다. 전달된 뒤의 처리는 받는 앱의 방침을 따릅니다. 앱은 사용자가 고르지 않은 대상으로 내용을 보내지 않으며, 클립보드를 감시하거나 기록하지 않습니다.

4. 제3자 제공

앱은 개인정보를 수집하지 않으므로 제3자에게 제공하지 않습니다.

5. 보관과 삭제

앱 전용 공간의 정보는 앱 안에서 지우거나, Android 설정에서 앱 데이터를 지우거나, 앱을 삭제하면 사라집니다. 사용자가 직접 저장한 파일은 앱을 삭제해도 그대로 남으며, 사용자가 파일 앱 등에서 직접 지울 수 있습니다. 개발자가 보관하는 사용자 정보는 없으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

6. 아동

앱은 13세 미만 아동을 대상으로 하지 않습니다.

7. 방침 변경

앱에 광고 등 정보 처리 방식이 바뀌는 기능이 추가되면, 그 기능이 포함된 버전을 배포하기 전에 이 방침을 고치고 시행일을 갱신합니다.
